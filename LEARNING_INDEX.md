# Learning index

A curated route through my public repositories. Start with the flagship projects, then explore the smaller labs for individual concepts. This is a navigation guide, not a claim that every repository is production-ready.

## Networking and systems

- [Firewall Hardening Lab](https://github.com/jfrance167/firewall-hardening-lab) — nftables policy, exposure measurement, and scoped rollback; includes sanitized VM evidence.
- [Python TCP Port Scanner](https://github.com/jfrance167/python-tcp-port-scanner) — TCP connectivity, concurrency, service labels, and reporting for authorized lab targets.
- [Network Forensics PCAP Lab](https://github.com/jfrance167/network-forensics-pcap-lab) — synthetic packet evidence and investigation.
- [Wireshark Traffic Analysis Lab](https://github.com/jfrance167/wireshark-traffic-analysis-lab) — DNS, TCP, TLS, filters, and evidence handling.
- [DNS Cache Semantics Lab](https://github.com/jfrance167/dns-cache-semantics-lab) — offline model of cached answers, cached denials, and fresh-query decisions.
- [Firewall Rule Analysis](https://github.com/jfrance167/fwrule) — modeled rule relationships and shadowing, with explicit limits.

## Detection and incident response

- [Automated Phishing Triage Toolkit](https://github.com/jfrance167/automated-phishing-triage-toolkit) — email parsing, optional enrichment, and explainable reports.
- [SIEM Detection Engineering Lab](https://github.com/jfrance167/siem-detection-engineering-lab) — offline multi-source correlation and ATT&CK-mapped alerts.
- [SIEM Logging Pipeline](https://github.com/jfrance167/siem-logging-pipeline) — local collection, transport, storage, LogQL, and Grafana dashboards.
- [Ransomware Incident Response Lab](https://github.com/jfrance167/ransomware-incident-response-lab) — synthetic attack-chain analysis and benign controls.
- [Windows Event Log Investigation](https://github.com/jfrance167/windows-event-log-investigation) — Windows telemetry analysis and incident timelines.
- [Failed Login Detector](https://github.com/jfrance167/failed-login-detector) — authentication-failure analysis across supported local input formats.
- [File Integrity Monitor](https://github.com/jfrance167/file-integrity-monitor) — SHA-256 baselines, metadata changes, and reporting.

## Evidence and attribution

For exact commands, results, dependencies, licenses, and AI-assistance details, follow each repository's documentation. Synthetic samples demonstrate behavior under controlled assumptions; historical validation records are dated evidence, not a current CI guarantee. Never interpret an educational model as validation of a production system.
